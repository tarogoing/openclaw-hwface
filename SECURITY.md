# Security Policy

## Supported Versions

This project is pre-1.0. Security fixes are handled on the main branch until a formal release policy exists.

## Reporting a Vulnerability

Please report security issues privately before opening a public issue.

Preferred contact:

- GitHub Security Advisories, if enabled for the repository.
- If advisories are unavailable, open a minimal public issue asking for a private security contact without including exploit details.

Please include:

- Affected component: Android app, OpenClaw v1 interface, or browser extension.
- Steps to reproduce.
- Impact and expected behavior.
- Any relevant logs with secrets redacted.

## Sensitive Data

Do not include real Gateway tokens, private hostnames, personal files, or production credentials in issues, PRs, screenshots, or test fixtures.
