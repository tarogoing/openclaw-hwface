# OpenClaw 浏览器扩展隐私政策

最后更新：2026-03-21

## 摘要

OpenClaw Browser Extension 是一个用于连接用户自行配置的 OpenClaw Gateway 的客户端。
它会存储本地扩展设置，并且只会将聊天请求发送到用户在扩展设置中填写的 Gateway URL。

## 扩展处理的数据

扩展可能处理以下数据：

- 用户填写的 Gateway 连接设置，包括 Base URL 和可选的 Gateway token 或密码
- 聊天 prompt 和模型回复
- 用户明确附加的文件或图片
- 存储在浏览器扩展存储中的本地会话历史
- 发送请求所需的基础请求元数据，例如 model、agent ID 和 session key

## 数据用途

扩展仅将这些数据用于：

- 连接用户配置的 OpenClaw Gateway
- 发送用户请求的聊天和附件请求
- 在浏览器扩展存储区域中保存本地设置和会话状态
- 在设置页中显示可选的、已脱敏的图片调试信息

## 数据发送位置

扩展只会将请求数据发送到用户配置的 OpenClaw Gateway URL。
扩展不会将用户数据发送到本仓库维护者运营的任何中转服务。

## 数据共享

扩展不会出售用户数据。
除正常运行时向用户配置的 OpenClaw Gateway 发送请求外，扩展不会与第三方共享用户数据。

## 数据存储

设置、本地会话历史和可选图片调试数据会通过浏览器扩展存储保存在本地。
除非用户自己的浏览器账号设置启用了扩展数据同步，否则这些数据会留在用户设备上。

## 敏感信息

如果用户输入 Gateway token 或密码，该值会保存在扩展存储中，并且只用于向配置的 Gateway 发起认证请求。
扩展不会将该凭证暴露给网页。

## 用户控制

用户可以：

- 在扩展设置页中更新或删除已保存设置
- 通过清理扩展存储或移除扩展删除本地会话历史
- 在发送请求前移除已附加文件
- 随时卸载扩展

## 安全

扩展不会注入用于让任意网站读取设置或凭证的网页桥接。
请求只会从扩展页面和后台 service worker 发起。

## 联系方式

如需报告隐私或安全问题，请使用本项目 `SECURITY.md` 中列出的报告渠道。公开托管版本建议使用：`https://openclaw-hwface.github.io/privacy/browser-extension/`。
